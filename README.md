# Fake News Detection System

A machine learning based web application that analyzes news content and predicts whether it is likely to be **REAL** or **FAKE**.

## 🚀 Features

- News headline and article analysis
- REAL / FAKE prediction
- Confidence score
- Confidence progress bar
- Loading spinner
- Example news for quick testing
- Prediction history
- Clear prediction history
- Dark mode / Light mode
- Responsive user interface
- REST API using FastAPI

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- CSS

### Backend
- Python
- FastAPI
- Uvicorn

### Machine Learning
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Pandas
